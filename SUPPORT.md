# Support

Thanks for using **DeepRAG** — a PyTorch framework for building and training RAG models with a fully differentiable retrieval step.

## Getting help

- **Usage questions & ideas** — open a [GitHub Discussion](https://github.com/AyhamJo7/deeprag/discussions) (or an issue if Discussions is not enabled).
- **Bugs & unexpected behavior** — open a [GitHub Issue](https://github.com/AyhamJo7/deeprag/issues) using the bug template. Include your Python/PyTorch versions, a minimal reproduction, and the full traceback.
- **Feature requests** — open an issue with the feature template and describe the use case.

## Before opening an issue

1. Check the [README](README.md) for setup and usage.
2. Search [existing issues](https://github.com/AyhamJo7/deeprag/issues?q=) — your question may already be answered.
3. Confirm you are on a supported Python (3.11+) and a recent PyTorch release.

## Security

Please do **not** report security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md) for private disclosure.

## Response expectations

This is a research/portfolio project maintained on a best-effort basis. Issues are triaged as time allows — there is no commercial SLA.
